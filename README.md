# TikTok Engagement & Virality Analysis

## Overview
Analyzed social media data to identify what drives the highest 
engagement and virality for small business content creators.

## Business Problem
What factors drive the highest engagement-to-conversion rate 
on social media for small businesses?

## Key Analyses
- Engagement rate by time posted
- Hashtag count vs views
- Sound type impact on shares
- Caption length vs engagement
- Viral vs non-viral content trait comparison
- Decision tree model to predict virality

## Tools
Python · Pandas · Seaborn · Matplotlib · Scikit-learn

## Dataset
Custom social media performance dataset (TT.csv, TT2.csv)
